# Правила работы в Sunny Rentals

## Экономные проверки — указание владельца от 19 октября 2026

- При обычных правках сайта (отступы, фон, футер, компоненты и подобное) не запускать Playwright/Chromium, не создавать и не просматривать браузерные скриншоты по умолчанию: визуальный результат проверяет сам владелец.
- Выполнять только соразмерные изменению проверки кода: целевые тесты, проверку типов/сборку при необходимости и diff-check. Не повторять полную сборку и широкую матрицу проверок для каждой мелкой визуальной правки. Логи возвращать кратко; подробности читать только при ошибке.
- Браузерные проверки обычного сайта запускать по прямому запросу владельца. Если конкретную проблему невозможно достоверно диагностировать без браузера, сначала объяснить необходимость и согласовать такой запуск.
- Для статей сохранять Playwright/Chromium и существующие проверки предпросмотра и опубликованных страниц, особенно для будущей автоматической подготовки/публикации. Это правило не отключает article browser gates и не включает автоматическую публикацию или одобрение статей.
- В ответе различать выполненные проверки кода и визуальную проверку владельцем; не утверждать, что интерфейс проверен в браузере, если такой проверки не было.
