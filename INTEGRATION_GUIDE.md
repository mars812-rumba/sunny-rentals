# Sunny Rentals - Руководство по интеграции## ОбзорSunny Rentals - это мобильное веб-приложение для аренды автомобилей на Пхукете, интегрированное с Telegram Web App.## Технический стек- **Frontend**: React 18 + TypeScript + Vite- **Стилизация**: Tailwind CSS + shadcn/ui- **Дата-пикер**: react-day-picker v8- **Иконки**: Lucide React- **Роутинг**: React Router DOM v6## Структура проекта```src/├── components/│   ├── ui/                 # shadcn/ui компоненты│   ├── HeroBanner.tsx      # Главный баннер│   ├── FilterForm.tsx      # Форма фильтров (даты, доставка, категории)│   ├── CarList.tsx         # Список автомобилей│   ├── CarCard.tsx         # Карточка автомобиля│   └── BookingModal.tsx    # Модальное окно бронирования├── pages/│   └── Index.tsx           # Главная страница├── assets/│   └── sunny-rentals-logo.jpg└── index.css              # Глобальные стили и дизайн-токены```## Интеграция с backend### API эндпоинтыПриложение ожидает следующие эндпоинты:1. **GET `/api/cars`** - получение данных об автомобилях   - Возвращает: JSON структуру из `public/data/web_cars.json`2. **POST `/api/booking`** - отправка заявки на бронирование   - Принимает:   ```json   {     "car": { /* объект автомобиля */ },     "startDate": "2024-01-01",     "endDate": "2024-01-15",      "days": 14,     "pickupLocation": "airport",     "returnLocation": "airport",     "whatsapp": "+7900000000"   }   ```### Структура данных автомобиля```json{  "id": "toyota_yaris_2022_black",  "name": "Toyota YARIS Sedan 2022 Black",  "class": "compact|suv|hatchback|minivan",  "brand": "Toyota",  "model": "YARIS",   "color": "Black",  "year": "2022",  "photos": {    "main": "путь/к/главному/фото.jpg",    "gallery": ["путь1.jpg", "путь2.jpg"]  },  "pricing": {    "low_season": {      "price_1_4": 928,      "price_5_14": 782,       "price_15_29": 684,      "price_30": 439    },    "high_season": { /* аналогично */ },    "deposit": 5000  },  "specs": {    "fuel": "Бензин",    "engine": "1,496CC",     "power": "91 л.с.",    "transmission": "Автомат",    "features": ["Кондиционер", "Камера заднего вида"]  }}```## Логика ценообразования- **1-4 дня**: `price_1_4`- **5-14 дней**: `price_5_14` - **15-29 дней**: `price_15_29`- **30+ дней**: `price_30`Доставка:- Аэропорт: бесплатно (0 ฿)- Отель/Вилла: +500 ฿## Telegram Web App интеграция### Инициализация```javascript// В main.tsx или App.tsxif (window.Telegram?.WebApp) {  window.Telegram.WebApp.ready();  window.Telegram.WebApp.expand();}```### Отправка данных в бота```javascriptconst sendToBot = (bookingData) => {  if (window.Telegram?.WebApp) {    window.Telegram.WebApp.sendData(JSON.stringify(bookingData));  }};```## Развертывание### Сборка проекта```bashnpm run build```### Настройка веб-сервера (Nginx)```nginxserver {    listen 80;    server_name sunny-rentals.online;        location / {        root /path/to/dist;        try_files $uri $uri/ /index.html;    }        location /api/ {        proxy_pass http://localhost:5000;  # Flask backend    }        location /images_web/ {        root /path/to/photos;    }}```## Адаптивность- **Мобильный**: до 768px (основной фокус)- **Планшет**: 768px -
