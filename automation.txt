# 📋 ПЛАН РАЗРАБОТКИ SEO-КОНТЕНТА ДЛЯ SUNNY RENTALS

## ОБЗОР
Создать два React компонента для динамического отображения контента (офферы и блог статьи), которые будут получать данные из JSON файлов. Контент генерируется автоматически, проверяется, и затем отображается на сайте.

## ЧАСТЬ 7: WORKFLOW ПРОЦЕСС

### 7.1 Как это работает:

```
1. Браток запускает скрипт:
   python3 seo_content_generator.py
   
2. Генерируется контент:
   /tmp/seo_content/offer_*.json
   /tmp/seo_content/blog_*.json
   
3. Браток проверяет как копирайтер:
   "Окей, текст норм" ✅
   
4. Контент попадает в:
   public/content/offers/
   public/content/blog/
   
5. Frontend читает JSON:
   const offers = await getAllOffers()
   
6. React рендерит компоненты:
   <OffersPage offers={offers} />
   
7. Пользователь видит:
   https://sunny-rentals.online/offers/
   https://sunny-rentals.online/blog/
   
8. Нажимает на статью → видит контент
   https://sunny-rentals.online/offers/arenда-avto-na-2-nedeli-v-mae/
   
9. Есть кнопка "Забронируй" → на форму с параметрами
   https://sunny-rentals.online/booking?days=14&location=phuket
```

## ЧАСТЬ 8: ПРИМЕРЫ ФАЙЛОВ

### 8.1 Пример компонента OfferCard.tsx

```tsx
import React from 'react'
import Link from 'next/link'
import { Button } from '@/components/ui/button'
import { Card } from '@/components/ui/card'

interface OfferCardProps {
  title: string
  slug: string
  content: string
  cta: string
  cta_color?: 'primary' | 'secondary'
}

export const OfferCard: React.FC<OfferCardProps> = ({
  title,
  slug,
  content,
  cta,
  cta_color = 'primary'
}) => {
  const preview = content.split('\n')[0].slice(0, 150) + '...'
  
  return (
    <Card className="h-full flex flex-col p-6 hover:shadow-lg transition">
      <h3 className="text-lg font-bold mb-2">{title}</h3>
      <p className="text-gray-600 text-sm mb-4 flex-1">{preview}</p>
      
      <Link href={`/offers/${slug}`}>
        <Button className={`w-full`} variant={cta_color === 'primary' ? 'default' : 'outline'}>
          {cta}
        </Button>
      </Link>
    </Card>
  )
}
```

### 8.2 Пример страницы оффера /offers/[slug].tsx

```tsx
import { getOffer, generateBookingUrl } from '@/utils/contentLoader'
import { notFound } from 'next/navigation'
import ReactMarkdown from 'react-markdown'
import { Button } from '@/components/ui/button'

interface PageProps {
  params: {
    slug: string
  }
}

export async function generateMetadata({ params }: PageProps) {
  const offer = await getOffer(params.slug)
  if (!offer) return {}
  
  return {
    title: offer.title,
    description: offer.meta_description,
    keywords: offer.meta_keywords,
  }
}

export default async function OfferPage({ params }: PageProps) {
  const offer = await getOffer(params.slug)
  
  if (!offer) return notFound()
  
  const bookingUrl = generateBookingUrl(offer.url_params)
  
  return (
    <div className="max-w-4xl mx-auto py-12 px-4">
      <h1 className="text-4xl font-bold mb-6">{offer.title}</h1>
      
      <article className="prose prose-lg max-w-none mb-8">
        <ReactMarkdown>{offer.content}</ReactMarkdown>
      </article>
      
      <div className="bg-blue-50 p-8 rounded-lg text-center">
        <h2 className="text-2xl font-bold mb-4">{offer.cta}</h2>
        <Button 
          size="lg" 
          className="px-8"
          onClick={() => window.location.href = bookingUrl}
        >
          Перейти на бронирование
        </Button>
      </div>
    </div>
  )
}
```
