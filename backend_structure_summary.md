# Sunny Rentals - Backend Project Structure Summary

## Connection Check ✅

Связь проверена успешно. Проект представляет собой комплексную систему аренды автомобилей на Пхукете с интеграцией ИИ и Telegram ботом.

## Архитектура Системы

### 🏗️ Основные Компоненты

**1. Backend API (`web_integration.py`)**
- **FastAPI** приложение (порт 5000)
- **Админ-панель** для управления флотом
- **CRM система** для работы с клиентами
- **Интеграция с Claude AI** для автоматического обслуживания
- **Система бронирования** с проверкой пересечения дат
- **Многопоточность** для обработки запросов

**2. Telegram Bot (`telegram_bot.py`)**
- **pyTelegramBotAPI** для взаимодействия с пользователями
- **WebApp интеграция** для каталога автомобилей
- **Система команд** и меню для администраторов
- **Уведомления** в групповые чаты
- **Автоматизация** через Claude AI

**3. Система Данных**
```
data/
├── user_data.json          # Пользователи и их статусы
├── bookings.json           # Бронирования
├── chat_logs.jsonl        # Логи чатов
├── crm_history.jsonl      # История CRM событий
├── car_owners.json        # Владельцы автомобилей
└── archive.json           # Архив пользователей
```

### 🤖 AI Integration (Claude)

**Функции Claude AI:**
- **Автоматический подбор** автомобилей
- **Диалоговая система** с клиентами
- **Анализ потребностей** пользователя
- **Управление состояниями**: активен/пауза/стоп
- **Интеграция с каталогом** автомобилей

**API Endpoints для Claude:**
- `/api/claude/start` - запуск диалога
- `/api/claude/stop` - остановка
- `/api/claude/pause` - пауза
- `/api/claude/resume` - возобновление
- `/api/claude/send_message` - отправка сообщений

## 🔧 Детальная Архитектура

### Backend API (web_integration.py)

**Основные функции:**
- **Файловая структура**: Модульная организация с разделением на утилиты, модели, endpoints
- **Асинхронность**: Использование threading.Lock() для thread-safe операций с файлами
- **API документация**: Автоматическая генерация через FastAPI docs/re docs
- **Middleware**: CORS для веб-интерфейса и Telegram WebApp
- **Статические файлы**: Обслуживание изображений автомобилей

**Ключевые модули:**
- **Модели данных**: Pydantic модели для валидации
- **Утилиты**: Функции для работы с файлами, датами, форматированием
- **Система диалогов**: Функции для управления состоянием разговоров
- **Интеграция AI**: Claude API для автоматизации обслуживания

### Telegram Bot (telegram_bot.py)

**Архитектурные особенности:**
- **Модульная структура**: Разделение на обработчики, утилиты, системы уведомлений
- **Безопасность**: Обработка ошибок отправки сообщений, проверка админов
- **Event-driven**: Обработка callback'ов, команд, сообщений
- **Интеграция с backend**: HTTP клиент для взаимодействия с FastAPI

**Системы уведомлений:**
- **Групповые чаты**: Разделение по типам лидов (горячие/теплые/активные)
- **Персональные уведомления**: Админ-панель для менеджеров
- **Real-time мониторинг**: Отслеживание состояний диалогов

### Система Данных

**Файловая структура:**
- **user_data.json**: Основная база пользователей с метаданными
- **bookings.json**: Система бронирований с валидацией дат
- **chat_logs.jsonl**: Логи всех сообщений для аналитики
- **crm_history.jsonl**: История CRM событий для аудита
- **archive.json**: Архив старых записей с автоматической очисткой

**Валидация и целостность:**
- **Thread-safe операции**: Использование lock'ов при записи
- **Backup стратегия**: Временные файлы с атомарными заменами
- **Миграция данных**: Автоматическое создание недостающих файлов

## 📈 Производительность и Масштабирование

**Текущие оптимизации:**
- **Кэширование**: В памяти для часто запрашиваемых данных
- **Lazy loading**: Загрузка данных по требованию
- **Batch операции**: Массовое обновление цен и статусов
- **Асинхронность**: FastAPI для обработки множественных запросов

**Потенциальные улучшения:**
- **База данных**: Переход на PostgreSQL/MySQL для больших объемов
- **Redis**: Кэширование сессий и real-time данных
- **Message Queue**: Для асинхронной обработки уведомлений
- **Load Balancing**: Для горизонтального масштабирования
