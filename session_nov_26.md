## 1. Итоговое видение продукта

«Sunny Platform» — это комплексная цифровая экосистема для управления арендным бизнесом, глубоко интегрированная в Telegram. Платформа состоит из следующих ключевых модулей:

*   **Клиентский контур:**
    *   **Telegram Web App (TWA):** Интерактивный веб-каталог с фильтрами, открывающийся внутри Telegram.
    *   **AI-бот:** Консультант, отвечающий на вопросы клиентов в чате.

*   **Административный контур:**
    *   **Веб-панель (Admin CRUD):** Мощный веб-интерфейс для полного управления автопарком, ценами и контентом.
    *   **Telegram-интерфейс:** Мобильный пульт для получения уведомлений и оперативного управления.

*   **Ключевая особенность (Userbot):**
    *   Проактивный бот для "дожима" клиентов, которые выбрали фильтры, но не совершили бронирование.

### 2.2. Техническое описание (Версия 2.0)

**Продукт:** «Sunny Platform» v1.0

**1. Обзор системы**
«Sunny Platform» — это комплексное клиент-серверное решение для автоматизации арендного бизнеса, построенное на API-first подходе. Система состоит из бэкенда на Python (FastAPI) и фронтенда на React (TypeScript), глубоко интегрированных с API Telegram.

**2. Архитектура и компоненты**

*   **2.1. Бэкенд (Серверное приложение)**
    *   **Технологии:** Python 3.12+, FastAPI, Uvicorn.
    *   **Описание:** Асинхронный REST API сервер, являющийся ядром системы.
    *   **Хранение данных:** JSON-файлы (`web_cars.json`, `bookings.json`). Архитектура позволяет легко мигрировать на реляционную СУБД.

*   **2.2. Фронтенд (Клиентское TWA и Веб-панель администратора)**
    *   **Технологии:** React 18+, TypeScript, Vite, Tailwind CSS, shadcn/ui.
    *   **Описание:** Единое одностраничное приложение (SPA), разделенное на клиентскую и административную части.

*   **2.3. Telegram-бот**
    *   **Технологии:** Python (предположительно, `aiogram` или `python-telegram-bot`).
    *   **Описание:** Обрабатывает команды, запускает TWA, отправляет уведомления.
    *   **Интеграция с AI:** Использует RAG-подход для ответов на вопросы на основе `knowledge_base.txt`.

*   **2.4. Веб-панель администратора (Admin CRUD)**
    *   **Технологии:** React, TypeScript (часть того же фронтенд-проекта).
    *   **Описание:** Отдельный раздел сайта (`/admin`) для CRUD-операций.

*   **2.5. Модуль проактивного Userbot'а**
    *   **Описание:** Уникальный компонент для автоматического вовлечения "горячих лидов".
    *   **Триггер:** Пользователь подобрал фильтры в TWA, но не инициировал бронирование.
    *   **Логирование:** Данные сессии (ID, даты, категория) сохраняются в лог `filter_completed`.
    *   **Механизм работы:** Администратор через Telegram может просмотреть лиды и запустить для них Userbot'а, который начинает диалог от имени сервиса.

**3. Процесс развертывания**
(Требования: Linux, Python 3.10+, Node.js 18+, Nginx/Caddy. Шаги: сборка фронтенда, запуск FastAPI, запуск бота, настройка прокси).

**4. Кастомизация и расширение**
(API-first подход, возможность замены БД, легкое добавление категорий, брендирование).
