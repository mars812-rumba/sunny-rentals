# Sunny Rentals: поэтапная миграция публичного сайта на Next.js

## Цель

Перенести только публичный маркетинговый и SEO-контур на Next.js, сохранив
Telegram WebApp, CRM, админку и FastAPI без изменения их рабочих URL и контрактов.

## Владение маршрутами

### Next.js marketing

- `/`
- `/cars/*`
- `/locations/*`
- `/blog/*`
- `/offers/*`
- `/sitemap.xml`
- `/robots.txt`

### Vite legacy app

- `/app`
- `/admin`
- `/admin/*`
- `/dashboard`
- `/offer`
- `/assets/*` на время перехода

### FastAPI и Telegram

- `/api/*`
- `/botapi/*`
- `/telegram/*`
- `/web_images/*`

Текущая Vite-сборка загружает JavaScript и стили из `/assets/*`. Этот маршрут
должен оставаться на legacy frontend, пока Vite не получит отдельный base path.
Иначе после переключения WebApp потеряет JavaScript и стили.

## Этапы

### 1. Изолированный фундамент

- Создать `apps/marketing`.
- Добавить App Router, metadata, robots, sitemap и manifest.
- Не менять production proxy и текущую Vite-сборку.

### 2. Главная страница

- Перенести текущий визуальный дизайн Sunny Rentals.
- Сохранить передачу дат, категории и доставки в Telegram.
- Показать по четыре модели в каждой категории.
- Вести карточки на статические SEO-страницы `/cars/[slug]`.
- Передавать выбранную модель в Telegram через `sr2` handoff.
- Оставить `/app` на текущем Vite SPA.
- Проверить Core Web Vitals и мобильную версию.

### 3. SEO-контент

- Перенести `/blog` и `/offers` с клиентского fetch на серверное чтение контента.
- Добавить статические страницы категорий и районов.
- Добавить уникальные metadata, canonical, Open Graph и JSON-LD.
- Генерировать URL через sitemap.

### 4. Переключение трафика

- Настроить reverse proxy по таблице владения маршрутами.
- На первом cutover передать Next.js только `/`, `/cars/*`, SEO-файлы и
  `/_next/*`; остальные публичные страницы оставить на Vite до миграции.
- Запускать Next.js standalone на `127.0.0.1:3100` за nginx.
- Добавить постоянные редиректы для изменившихся URL.
- Проверить прямое открытие `/app`, `/admin` и вложенных страниц.
- Проверить Search Console, robots, sitemap и structured data.

### 5. База данных

- Сохранить FastAPI единой точкой бизнес-логики.
- Перевести бронирования, автомобили и CRM с JSON на базу данных.
- Не связывать миграцию базы с миграцией публичного сайта.

## Правила безопасного переключения

- Один URL обслуживается только одним приложением.
- Между Next.js и Vite используются обычные `<a>`-переходы.
- `/app` и служебные маршруты закрыты от индексации.
- До production cutover текущая главная Vite остаётся источником трафика.
- Переключение выполняется только после отдельной проверки production-сборок.
