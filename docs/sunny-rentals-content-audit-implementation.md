## Общий источник условий

`content/rental-policy.ts`: ранее опубликованные тарифы аэропорта/города,
кресло по запросу, чистая машина/полный бак, суммы франшизы и описание ограничений.
Карточки, FAQ и страницы используют эти данные. Депозит и аренда остаются
в инвентаре; тарифы, сезоны, алгоритм расчёта и данные бронирований не изменены.

Описание страховки больше не представляет требование второй стороны
универсальным свойством класса 1. На байке отсутствие покрытия повреждений
не объявляется отсутствием всех возможных обязательных полисов.
Полную таблицу страховых случаев нельзя составить без документов.

В JSON-LD убрано неподтверждённое наличие: live-источника остатков нет.
FAQ остаётся в HTML внутри native details/summary.
Новая разметка FAQPage и обещания расширенного сниппета не добавлялись.

## Характеристики и фотографии

Подготовлен опциональный контракт `public_details` для конкретного транспорта:
source, verifiedAt, seats, bodyStyle RU/EN, equipment RU/EN,
childSeatCompatible, luggage.photos и описание положения сидений RU/EN.
Поля показываются только при наличии источника и даты подтверждения.
Новые характеристики в инвентарь не записывались.
Наличие кресла по запросу не считается подтверждением совместимости конкретной машины.
Пока такой информации нет, семейная страница предлагает совместный подбор и
не выдаёт случайные машины за проверенную подборку.

Для первого пакета нужны 3–5 востребованных машин: фото багажника при используемых
рядах, салона/креплений кресел; для байков — реальная комплектация и шлемы.
Число чемоданов, ABS, ISOFIX и CarPlay по названию модели не присваиваются.
Противоречия исходных характеристик (например, двигатель BYD Seal,
CBR500R/650 cc и бренд H1) требуют подтверждения поставщика, а не угадывания.

## Что нужно от владельца для завершения P0 и ответов C

Эти пункты пока не опубликованы как конкретные правила. Внутренние пустые
поля, TODO и обещания «будет уточнено» в публичный контент не добавлены.

| Пункт | Требуемый факт |
|---|---|
| Исполнитель | Сторона договора, статус/название, кто выдаёт и принимает транспорт |
| Депозит | После осмотра авто — подтверждено; ещё нужны момент/способ/валюта внесения, точный срок/способ возврата, банковские задержки |
| Удержания | Основания из договора, расчёт суммы, акт/фото/документы, контакт спора |
| Предоплата/оплата | Для авто: высокий сезон — 1000 бат, низкий — обычно без предоплаты; ещё нужны срок, момент подтверждения, зачёт в аренду, способы и комиссии |
| Отмена | При отмене клиентом авто в высокий сезон 1000 бат не возвращаются; ещё нужны отмена оператором, неявка, перенос, досрочная сдача |
| Документы | Возраст/стаж/оригиналы, паспорт/копия/залог, второй водитель |
| Доставка | 500 бат по городу в одну сторону — подтверждено; ещё нужны границы зон, парковка и дополнительные сборы |
| Рейс/ночь | Рабочие часы выдачи, доплаты, ожидание, кто отслеживает задержку |
| Срок | Минимум по машинам/сезонам, сутки/лишние часы, продление |
| Поездки | Пробег/превышение, разрешённые провинции, паромы, ограничения |
| Возврат | Уровень топлива как при получении — подтверждено для авто; ещё нужны расчёт недостачи, обычная/сильная грязь, мойка |
| Поддержка | Телефон при ДТП/поломке, часы Asia/Bangkok, помощь вне часов, эвакуация/замена |
| Полис авто | Коммерческая аренда, вторая сторона/без неё, парковка, стёкла/шины, кража, вода; франшиза по случаю |
| Байк | Ущерб байку, обязательные полисы, третьи лица, медицина и кража отдельно |
| Семья/комплектация | Модели кресел и ограничения производителя, совместимость, два кресла; опции байков и шлемы |

После ответа данные нужно внести один раз в источник условий, затем синхронно
обновить RU/EN, FAQ C и профильные страницы. Не копировать правила конкурентов.

## Каноничность, цены и локализация

Семейства моделей по-прежнему индексируются через стабильный master, а
страницы экземпляров сохраняют собственные рабочие URL и ссылки бронирования.
Canonical, hreflang и sitemap проверяются экспортным SEO-валидатором.
Нормализация названия не изменяет booking ID.
Последнее существенное изменение контента зафиксировано датой 2026-10-06;
сборка не подменяет lastmod текущей датой автоматически.

Минимальная ставка может относиться к другому сезону, чем открытая таблица.
Для NMAX сравнивайте активный сезон, тариф 30+ и выбранные даты; тарифная
разница не объявлялась багом и значения не переписывались.

Официальный источник документов проверен при внедрении:
[Government PRD: driving eligibility](https://thailand.prd.go.th/en/content/category/detail/id/2874/iid/341038).
Он не подтверждает собственные правила выдачи Sunny или условия страховщика.
На страницах документов/байков добавлена обычная ссылка на источник.

## Проверки и превью

Webpack production build создаёт статическое превью в apps/marketing/out.
Команды verify-seo и verify-content проверяют canonical/hreflang,
существование внутренних ссылок, RU/EN и ответы FAQ в исходном HTML.
Отдельные тесты проверяют сохранение ID/тарифов/handoff, перевод и отсутствие
выдуманных опций, различия вопросов сценариев.
Реальные заявки не отправлялись.

В текущей среде нет доступного браузера; интерактивная визуальная проверка
мобильного экрана и клавиатуры остаётся ручной проверкой превью.
FAQ использует штатное управление details/summary и существующий focus-visible;
это проверка структуры, а не замена браузерного UX-теста.

## Измерение после публикации

Через 2–4 недели собрать повторяющиеся вопросы и воронку:
карточка → даты → Telegram → отправленная заявка → подтверждённая бронь.
Клик по Telegram отдельно от лида. Разделять RU/EN, авто/байки, сценарии и
источники. Не передавать личные документы, телефоны и переписки в analytics URL.
SEO оценивать на более длинном периоде с учётом сезона и реального объёма данных.
